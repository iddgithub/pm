# 01_agents

这里是 `pm_agent` 的能力层之一，专门放可复用的角色定义。

它解决的问题不是“业务事实存哪里”，而是“面对不同产品工作时，AI 应该以什么身份、按什么标准输出”。

## 与当前仓库的关系

- `01_agents/`：定义角色
- `02_tools/`：提供模板、清单、工作流
- `05_drafts/`：暂存未成型想法
- `04_workspace/`：推进中的专题工作
- `03_context/`：稳定复用的业务知识

也就是说，`01_agents/` 不替代现有三层结构，而是给这三层加一层“执行方法”。

- `角色定义/Context架构师.md`

## 使用原则

1. 一个角色只解决一类高频问题，不要把所有职责堆在一个文件里。
2. 角色文件只写目标、输入、输出、边界和落位，不写具体某次需求内容。
3. 当角色稳定后，再补充或拆分，不一开始就建几十个。

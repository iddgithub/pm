# 角色定义

## 用途

这里按角色拆分 PM 常见工作场景，让 Claude / Codex 在执行任务时有明确身份和输出边界。

## 当前文件

- `产品策略顾问.md` — 负责问题定义、目标澄清和方案取舍
- `需求分析师.md` — 负责把模糊诉求拆成结构化分析
- `PRD写作助手.md` — 负责把分析结果写成正式 PRD
- `会议纪要整理员.md` — 负责把原始会议内容整理成可行动记录
- `Bug归因助手.md` — 负责梳理问题现象、影响范围和排查方向
- `原型设计助手.md` — 负责整理页面结构、交互流程和原型边界
- `Demo验收助手.md` — 负责对 H5 / PC demo 做产品视角验收
- `Context架构师.md` — 负责维护仓库中的上下文结构和索引

## 规则

- 如果一个角色长期不使用，应合并或归档，而不是持续堆积
- 若角色能力明显跨越多个场景，优先拆成更聚焦的两个角色

# 05_drafts

`05_drafts/` 用来暂存还没成型的内容。

这里适合放灵感、碎片记录、半成品分析、方向探索，以及暂时不适合直接进入 `04_workspace/` 或 `03_context/` 的材料。

## 目录关系

- `方案探索/`：某个方向的初步判断、思路比较、可行性探索
- `临时记录/`：随手记下的想法、线索、素材、待处理事项

## 什么内容先放这里

- 还没想清楚值不值得做
- 背景信息不全，只能先做初步记录
- 只是一个方向，还没有进入正式专题推进
- 临时收到的会议碎片、口头需求、截图线索

## 什么时候离开这里

- 已经明确要推进：移到 `04_workspace/`
- 已经沉淀成稳定规则：提炼到 `03_context/`
- 确认无价值或过时：直接清理

## 推荐用法

1. 先快速记录，不要求一开始就完整
2. 通过补充背景、目标和限制，把草稿逐步结构化
3. 一旦进入正式推进，就迁移到更合适的位置

## 维护原则

- 草稿层允许不完整，但不应长期堆积不处理
- 过期内容要归档或删除，避免把草稿层变成垃圾桶
- 如果某个草稿已经形成明确专题，就不要继续留在这里

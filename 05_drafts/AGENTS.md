# Drafts

本文件是 Codex 使用的目录索引。

## 用途

这里存放尚未想清楚、尚未正式立项或仍在探索中的内容，是低门槛记录和发散思考的入口层。

## 子目录

- `临时记录/` — 快速想法、碎片记录、临时信息
- `方案探索/` — 方案对比、调研笔记、方向探索

## 规则

- 拿不准放哪里时，优先放进 `05_drafts/`
- 有价值的草稿在想清楚后进入 `04_workspace/`
- 已经验证并长期复用的内容再沉淀进 `03_context/`

# 03_context

`03_context/` 用来存放已经确认、适合长期复用的稳定知识。

这里不追求“最新讨论”，而追求“以后还可以反复引用”。当 `04_workspace/` 里的需求、规则或结论已经稳定，再提炼到这一层。

## 目录关系

- `01_产品架构/`：产品概览、术语、整体框架
- `02_功能模块/`：具体功能规则、模块说明
- `03_运营材料/`：可复用的运营口径与素材
- `04_参考附录/`：外部资料、补充参考
- `05_架构决策/`：关键决策及其原因
- `06_团队信息/`：团队分工、协作背景

## 什么时候放到这里

- 某条业务规则已经确认，不再只是讨论草稿
- 某份产品说明后续多个专题都会反复引用
- 某项决策需要留下长期可追溯记录

## 不适合放这里的内容

- 还在推进中的需求分析
- 尚未定稿的 PRD 或原型说明
- 临时会议碎片、待确认问题、一次性讨论

这类内容应先放在 `04_workspace/` 或 `05_drafts/`。

## 推荐用法

1. 先在 `04_workspace/` 完成分析、讨论和定稿。
2. 把已经稳定的规则提炼成更通用的表达。
3. 再放进 `03_context/` 对应分类目录。

## 维护原则

- 这里优先写“稳定事实”和“复用规则”
- 尽量避免把专题过程文档原样搬进来
- 内容过时后要及时更新，不要让稳定层变成旧资料堆

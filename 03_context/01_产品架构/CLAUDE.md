# 01_产品架构

## 用途

这里存放 AIcanTARA 的产品级基础上下文，包括产品概览、核心术语、立项背景，以及后续会长期复用的产品框架信息。

## 文件

- `产品概览.md` — 说明产品是什么、服务谁、解决什么问题
- `术语表.md` — 统一团队内部术语、缩写与表达
- `立项背景.md` — 记录为什么做这件事、问题来源与初始目标
- `pm_agent目录说明.md` — 说明整个 Context 仓库的目录职责、知识流转和维护约定
- `pm_agent日常工作对照表.md` — 按日常工作场景映射 skill、agent 与目录落位

## 规则

- 这里应优先沉淀稳定、长期复用的产品知识
- 这是后续重点维护的目录之一，用于承载产品经理工作的核心稳定语境
- 如果信息仍在快速变化，先放入 `05_drafts/` 或 `04_workspace/`
- 更新本目录内容后，应同步更新本文件和上级 [03_context/CLAUDE.md](/Users/hugaopeng/Desktop/pm_agent/03_context/CLAUDE.md)

# AIcanTARA 术语表

团队内部术语与常用表达。后续 AI 在生成文档、PRD、分析材料时，应尽量保持这些说法一致。

| 术语 | 定义 | 备注 |
|---|---|---|
| Context 工程 | 将上下文作为工程对象进行组织、沉淀、维护和复用的方法 | 是当前知识库设计的核心思想 |
| Context 仓库 | 专门为 AI 和团队协作服务的结构化知识库 | 当前仓库 `pm_agent/` 就属于此类 |
| context | 已确认、稳定、可复用的事实性知识 | 在目录结构中对应 `03_context/` |
| workspace | 正在推进中的工作内容 | 在目录结构中对应 `04_workspace/` |
| drafts | 尚未定型的草稿与探索内容 | 在目录结构中对应 `05_drafts/` |
| Skills | 标准化、可复用的 AI 工作方法或命令 | 通过 `.claude/commands/` 调用 |
| CLAUDE.md | 提供给 AI 使用的目录索引与上下文入口文件 | 与 `README.md` 的受众不同 |
| README.md | 面向人阅读的说明文档 | 常用于项目介绍和使用说明 |
| 种子文档 | 初始化知识库时先创建的第一批基础文档 | 用于让空结构尽快可用 |
| 知识沉淀 | 将阶段性成果提炼为长期复用知识的过程 | 常见流向是 `04_workspace/` 到 `03_context/` |

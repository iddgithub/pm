# Context

本文件是 Codex 使用的目录索引；同目录 `CLAUDE.md` 是 Claude 使用的目录索引，二者应保持一致。

## 用途

这里存放 AIcanTARA 已经确认的事实性知识，是 AI 进行高质量输出时应优先参考的稳定上下文。

## 子目录

- `01_产品架构/` — 产品框架、术语表、立项背景
- `02_功能模块/` — 已实现功能的详细设计
- `03_运营材料/` — 帮助手册、官网、客户沟通
- `04_参考附录/` — 行业标准、威胁知识库、客户标书
- `05_架构决策/` — ADR（架构决策记录）
- `06_团队信息/` — 团队成员信息

## 规则

- 只放已经确认、可复用、相对稳定的知识
- 新上线功能完成后，可从 `04_workspace/` 提炼后沉淀到这里
- 如果内容尚未确认，先放入 `05_drafts/` 或 `04_workspace/`
- 后续优先维护 `01_产品架构/` 与 `02_功能模块/`，以支撑产品经理工作的核心稳定语境

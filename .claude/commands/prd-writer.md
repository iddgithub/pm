# PRD Writer

当用户要求撰写、完善、重写 PRD 时，使用本命令。

## 目标

基于当前仓库中的专题资料，产出可评审、可执行的 PRD 文档。

## 执行要求

1. 先读 `analysis/` 和 `prototype/`，再写 `prd/`。
2. 输出尽量包含：
   - 背景
   - 问题定义
   - 目标
   - 非目标
   - 方案说明
   - 关键流程
   - 规则与边界
   - 风险与依赖
   - 待确认问题
3. 模糊点用“待确认”标记，不要编造业务事实。
4. 若用户要求重写，默认生成新文件而不是覆盖原稿。

## 落位规则

- 正式 PRD：`04_workspace/prd/某个专题/prd/`
- 草稿方案：`05_drafts/方案探索/`

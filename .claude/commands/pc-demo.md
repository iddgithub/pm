# PC Demo

当用户要求做后台页面、管理端原型、H5 或 PC 演示工程时，使用本命令。

## 目标

把演示工程统一沉淀到 `04_workspace/demos/`，与知识文档分层维护。

## 目录约定

- H5 工程：`04_workspace/demos/h5/`
- PC 工程：`04_workspace/demos/pc/`

## 执行要求

1. 先判断是 H5 还是 PC。
2. 页面、路由、菜单和 mock 数据要成套维护。
3. demo 工程只承接展示和交互，不承载稳定产品知识。
4. 若 demo 中形成长期复用规则，再提炼到 `03_context/` 或专题文档中。

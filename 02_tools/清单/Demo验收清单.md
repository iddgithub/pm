# Demo验收清单

演示前至少检查：

- 首页、列表页、详情页、弹窗页是否都能进入
- 关键主流程是否能从头走通
- 关键状态是否都有展示，不只展示理想状态
- 文案是否统一，按钮命名是否符合业务语义
- 页面完成后先自查排版：标题、卡片、表单、按钮、标签、说明文字是否存在挤压、溢出、错位、异常缩放或不合理换行
- 自查时至少覆盖桌面和当前主要演示尺寸，确认文字不重叠、模块不塌陷、主要信息不被截断
- 表单是否有默认值、校验和错误提示
- 表格、卡片、统计区是否存在明显假数据穿帮
- 菜单、面包屑、返回路径是否一致
- 空态、加载态、异常态是否至少覆盖最关键页面
- 演示用 mock 数据是否和当前业务规则一致
- 需要口头解释的地方，是否已提前准备备注

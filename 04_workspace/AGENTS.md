# Workspace

本文件是 Codex 使用的目录索引；同目录 `CLAUDE.md` 是 Claude 使用的目录索引，二者应保持一致。

## 用途

这里存放 AIcanTARA 当前正在推进的工作，是产品、运营与协作过程中最活跃的工作区。

## 子目录

- `prd/` — 按专题目录维护的需求分析、原型和 PRD
- `bugs/` — Bug 记录，可按负责人或状态组织
- `discussions/` — 大需求讨论记录
- `公众号/` — 公众号内容与选题产出
- `关键会议纪要/` — 重要会议记录
- `demos/` — H5 / PC 演示工程、运行脚本和说明

## 规则

- 这里记录“我们正在做什么”
- 已完成并沉淀为稳定知识的内容，应提炼后移入 `03_context/`
- 尚未成型的想法或原始素材，可先进入 `05_drafts/`

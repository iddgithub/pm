# 04_workspace/demos

## 目录定位

本目录只存放 H5 / PC 演示工程、守护脚本和运行说明。

## 当前约定

- H5 固定地址：`http://127.0.0.1:3001/`
- PC 固定地址：`http://127.0.0.1:3002/`
- 浏览器书签访问依赖本机 `launchd` 守护，不再使用临时 `nohup` 启动

## 维护要求

1. 新增 demo 运行脚本或说明时，同步更新本目录 `README.md` 与 `AGENTS.md`。
2. 默认通过 `demosctl.sh` 安装、查看状态、重启、卸载和打开浏览器。
3. demo 仍然使用 Vite 开发服务，保留热更新，不切换为静态托管方案。
4. 本目录只负责本地演示运行能力，不沉淀长期业务知识。

## 当前文件

- `README.md` — 演示工程的运行说明、日志位置和常见问题
- `demosctl.sh` — 本地守护安装、状态查看、重启和打开浏览器的统一入口
- `scripts/` — H5 / PC demo 共用脚本
- `h5/` — H5 演示工程
- `pc/` — PC 演示工程

## 忽略项

- `.runtime/` — 本地运行生成的状态和日志目录，不作为长期索引对象
- `h5/dist/`、`pc/dist/` — 构建产物目录，不手工维护索引
- `h5/node_modules/`、`pc/node_modules/` — 依赖目录，不手工维护索引

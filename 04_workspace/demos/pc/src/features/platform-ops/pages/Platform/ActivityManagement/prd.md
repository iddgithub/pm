# 活动管理 PRD

**文档状态**: Draft  
**需求名称**: 活动管理模块  
**负责人**: 待补充  
**创建日期**: 2026-05-23  
**最近更新**: 2026-05-23

## 1. 背景

为什么要做这个需求？

- 当前业务背景：平台需要统一管理面向不同渠道与机构的检查项目活动价，并支持在活动生命周期内进行创建、编辑、上下架和查看。
- 问题来源：活动价格配置涉及渠道、机构、检查项目、活动时间等多维度关系，若缺少统一后台，将难以保证价格生效范围清晰、活动冲突可控。
- 触发原因：需要在平台运营后台提供可运行的活动管理页面，以支撑活动价的录入、维护、展示和状态切换。

## 2. 问题定义

当前具体存在什么问题？问题影响了谁？影响体现在哪里？

- 目标用户：平台运营负责人。
- 当前痛点：缺少统一入口管理活动价，无法在同一页面中完成活动列表查看、活动配置、机构项目价格维护和活动详情核查。
- 现有方案缺陷：若手工管理渠道、机构和项目活动价，容易出现同一机构同一项目在同时间段重复配置、价格覆盖范围不清和活动状态难追踪的问题。

## 3. 目标

这个需求希望达成什么结果？

- 业务目标：建立活动价配置与状态管理能力，保证同一渠道下机构活动价可被统一维护。
- 用户目标：让平台运营负责人能够完成活动的新建、编辑、查看、上架、下架、删除及机构维度项目价格维护。
- 交付目标：交付一个包含列表页、表单编辑页和详情页的一体化后台活动管理模块，并支持普通后台路径与分享路径两种访问方式。

## 4. 非目标

这次需求明确不解决什么问题？

- 不在本次范围内的内容：不包含真实后端接口对接，不包含权限系统接入，不包含批量导入导出，不包含活动审核流。
- 暂不处理的边界：不处理跨渠道复用活动，不处理项目库维护能力，不处理活动价格自动推送链路的外部系统联调。

## 5. 用户场景

描述用户在什么情况下会使用这个能力。

### 场景 1

- 用户角色：平台运营负责人
- 使用前提：需要为某渠道下的一个或多个机构配置阶段性活动价
- 用户动作：进入活动管理页面，新建活动，选择渠道、机构、活动时间，并为各机构添加检查项目与活动价
- 预期结果：活动保存后立即以上架状态生效，并在列表中可见

### 场景 2

- 用户角色：平台运营负责人
- 使用前提：已有活动正在运行或已创建
- 用户动作：在列表页查看活动、进入详情核查机构价格、编辑活动，或执行上架、下架、删除操作
- 预期结果：活动状态和内容按操作更新，详情页与列表页展示同步变化

## 6. 方案说明

说明整体方案是什么。

- 核心方案：以单页面模块承载三类视图：活动列表、活动表单（新建/编辑）、活动详情。通过路由判断当前展示视图，并将活动数据持久化到本地存储。
- 与现有功能的关系：模块挂载于平台运营端"活动管理"菜单，同时支持后台主路径和分享路径访问；两类路径使用独立本地存储键保存数据。
- 为什么这样设计：统一由平台运营负责人创建活动，一个活动可绑定同一渠道下多个机构，每个机构独立维护项目活动价，既能减少重复建活动，也能清晰限制价格作用范围。

## 7. 关键流程

按步骤描述主要流程。

1. 用户进入：用户从平台运营端进入活动管理列表，查看当前所有活动记录。
2. 用户操作：用户可新建活动，填写基础信息并为每个机构配置项目活动价；也可从列表进入详情或编辑，或在列表/详情中执行上下架、删除。
3. 系统响应：系统校验必填项、时间范围、机构项目完整性及活动冲突规则，通过后保存数据并记录操作日志；上下架和删除前均弹出确认框。
4. 结果反馈：保存成功后提示"活动已保存并上架"并返回列表；上下架、删除成功后提示成功消息，列表和详情展示同步更新。

## 8. 功能需求

### 8.1 活动列表页 [1]

- 功能描述：展示活动管理总览，支持查看活动基础信息并执行查看、编辑、上架/下架、删除操作。
- 输入：本地存储中的活动数据。
- 输出：活动列表表格。
- 校验规则：无表单校验；上下架和删除操作前必须二次确认。
- 异常处理：当活动被删除后，不再展示；当活动状态受时间影响时，系统自动归一化为"已上架 / 进行中 / 已下架"。

#### 页面模块

- 页面标题：活动管理
- 页面副标题：统一由平台运营负责人创建；一个活动可绑定同一渠道下多个机构，每个机构独立维护项目活动价。
- 顶部操作：新建活动按钮
- 表格字段：
  - 序号
  - 活动名称
  - 所属渠道
  - 所属机构
  - 机构数
  - 活动项目数
  - 活动时间
  - 状态
  - 创建人
  - 更新时间
  - 操作
- 所属机构展示规则：
  - 机构数量不超过 2 家时，直接展示机构名称
  - 机构数量超过 2 家时，展示前 2 家机构名称并显示"等X家"
  - 多机构时支持点击"查看机构"弹出浮层查看完整机构列表
- 操作按钮：
  - 查看
  - 编辑
  - 下架（当前状态为"已上架"或"进行中"时显示）
  - 上架（当前状态为"已下架"时显示）
  - 删除
- 分页规则：每页 10 条，显示总记录数文案"共X条记录  当前显示X条记录"

#### 交互行为

- 点击"新建活动"进入新建页。
- 点击"查看"进入详情页。
- 点击"编辑"进入编辑页。
- 点击"下架"弹出确认框，确认后将活动状态更新为"已下架"，并追加"下架活动"日志。
- 点击"上架"弹出确认框，确认后将活动状态更新为"已上架"，并追加"上架活动"日志。
- 点击"删除"弹出危险确认框，确认后删除活动且不可恢复。

#### 状态规则

- 已下架：手动下架，或活动结束时间早于当前时间。
- 已上架：活动未开始但已保存上架，开始时间晚于当前时间。
- 进行中：当前时间处于活动开始和结束时间之间，且未手动下架。

### 8.2 活动新建/编辑页

- 功能描述：用于创建活动或修改已有活动，并按机构维护项目活动价。
- 输入：用户填写的基础信息、机构选择、活动时间、项目选择和活动价。
- 输出：一条保存后的活动记录，默认以上架状态写入活动列表。
- 校验规则：基础信息完整、结束时间晚于开始时间、每个选中机构至少配置一个项目且项目活动价完整、不得与其他未下架活动产生冲突。
- 异常处理：校验不通过时弹出错误消息，不保存数据。

#### 基础信息表单 [2]

- 字段：
  - 活动名称
    - 类型：输入框
    - 必填：是
    - 最大长度：30
    - 占位提示：例如：影像检查活动价A
  - 所属渠道
    - 类型：单选下拉
    - 必填：是
    - 可选值：渠道A、渠道B、渠道C
  - 所属机构
    - 类型：多选下拉
    - 必填：是
    - 依赖关系：需先选择所属渠道后可选
    - 占位提示：未选渠道时显示"请先选择所属渠道"，已选渠道后显示"请选择所属机构，可多选"
  - 活动时间
    - 类型：起止时间范围选择
    - 必填：是
    - 格式：YYYY-MM-DD HH:mm
  - 活动说明
    - 类型：多行文本
    - 必填：是
    - 最大长度：120
    - 占位提示：填写活动背景、沟通结论或展示说明
- 页面按钮：
  - 返回列表
  - 保存并上架

#### 机构项目活动价模块 [3]

- 模块目标：按机构分别维护活动项目和活动价。
- 模块说明：当前渠道下，每个机构独立配置项目和活动价；活动价只作用在该渠道下的当前机构。
- 机构切换：
  - 当所属机构有多个时，以切换按钮形式展示已选机构
  - 默认选中第一个机构；若当前激活机构被取消选择，则自动切换至新的第一个机构
- 顶部状态标签：
  - 已选择机构时显示"机构名 已添加 X 项"
  - 未选择机构时显示"未选择机构"
- 表格字段：
  - 项目名称
  - 编码
  - 原价
  - 活动价
  - 操作
- 操作说明：
  - 点击"添加检查项目"打开一级平台项目库弹窗
  - 在已选项目表格中可编辑活动价
  - 在已选项目表格中可点击"移除"移除项目
- 价格显示规则：
  - 原价显示带删除线价格
  - 活动价使用金额输入框录入，支持两位小数，最小值为 0

#### 一级平台项目库弹窗 [4]

- 功能描述：从标准检查项目库中为当前机构选择活动项目。
- 打开条件：当前已选定激活机构。
- 标题：一级平台项目库
- 顶部说明：
  - 已选机构时，提示当前为该机构添加平台标准检查项目，已添加项目和与其他活动冲突的项目自动禁选
  - 未选机构时，提示请先选择所属机构
- 冲突提示：当已选机构存在时间冲突项目时，展示提示"同渠道下，当前机构在所选活动时间内已被其他活动占用的项目将禁止选择，避免活动价格冲突。"
- 查询区字段：
  - 检查类型：下拉筛选，选项来自标准项目的类型去重结果
  - 编码/名称关键字：输入框
  - 查询：按钮
- 项目库表格字段：
  - 项目名称
  - 所属分类
  - 编码
  - 适用检查类型
- 行选择规则：
  - 已添加到当前机构的项目禁选
  - 当前机构未选中时全部禁选
  - 与其他活动冲突的项目禁选，并显示冲突活动名称与时间提示
- 确认添加行为：将选中的项目加入当前机构项目列表；若项目未配置活动价，则默认带入项目默认活动价或原价。
- 取消行为：关闭弹窗并清空已选项目、查询关键字和检查类型筛选条件。

#### 保存校验规则

- 活动名称不能为空。
- 活动说明不能为空。
- 所属渠道不能为空。
- 所属机构至少选择 1 个。
- 活动开始和结束时间必须完整选择。
- 结束时间必须晚于开始时间。
- 每个已选机构至少添加 1 个检查项目。
- 每个已选机构的每个检查项目都必须填写活动价。
- 同一渠道下，同一机构的同一检查项目在相同时间内只能存在一个活动价。
- 编辑时忽略当前正在编辑的活动自身，不与自身进行冲突比较。

#### 保存结果

- 新建活动时：
  - 生成新活动 ID
  - 创建人固定为"平台运营负责人"
  - 状态写入"已上架"
  - 写入"创建活动"日志
- 编辑活动时：
  - 覆盖原活动基础信息、机构配置和更新时间
  - 写入"编辑活动"日志
  - 若编辑前原状态不是"已上架"，额外追加"上架活动"日志
- 保存成功提示：活动已保存并上架
- 保存成功后跳转：返回活动列表页

### 8.3 活动详情页 [5]

- 功能描述：查看活动的基础信息、机构范围和每个机构下的项目活动价，并可从详情页返回、编辑或下架活动。
- 输入：指定活动 ID 对应的活动数据。
- 输出：活动详情视图。
- 校验规则：无编辑表单；仅在活动存在时展示详情。
- 异常处理：当活动不存在时，展示"未找到该活动。"并提供返回列表按钮。

#### 基础信息区域

- 展示字段：
  - 活动名称
  - 所属渠道
  - 活动状态
  - 活动时间
  - 创建人
  - 更新时间
  - 所属机构
  - 机构数
  - 活动项目数
  - 活动说明
- 状态展示：使用标签展示"已上架 / 进行中 / 已下架"

#### 机构活动项目价格区域

- 机构切换：展示该活动下全部机构按钮，点击切换当前查看机构。
- 说明文案：当前查看机构：机构名称。项目价格仅作用在该渠道下的当前机构。
- 表格字段：
  - 项目名称
  - 所属分类
  - 编码
  - 检查类型
  - 原价
  - 活动价
  - 价格变化
- 价格变化规则：活动价减去原价，若差值大于 0 则显示为正数且高亮为风险色，否则按普通文本展示。
- 顶部操作：
  - 返回列表
  - 编辑活动
  - 下架活动（仅当状态为"已上架"或"进行中"时显示）

#### 详情页交互行为

- 点击"返回列表"返回活动列表页。
- 点击"编辑活动"进入编辑页。
- 点击"下架活动"弹出确认框，确认后将活动状态更新为"已下架"，记录日志并提示"活动已下架"。

### 8.4 数据持久化与路由切换

- 功能描述：根据访问路径切换页面模式与数据存储范围。
- 输入：当前路由 pathname。
- 输出：对应视图和数据存储键。
- 校验规则：根据路径识别列表、新建/编辑、详情三种页面状态。
- 异常处理：本地存储读取失败时回退为预置种子活动数据。

#### 路由规则

- 后台主路径：/platform/activity-management
- 新建路径：/platform/activity-management/create
- 编辑路径：/platform/activity-management/edit/:id
- 详情路径：/platform/activity-management/:id
- 分享路径：/share/activity-management
- 分享路径下也支持新建、编辑、详情对应子路径

#### 存储规则

- 后台主路径使用本地存储键：pm-agent-activity-management-v4
- 分享路径使用本地存储键：pm-agent-activity-management-share-v2
- 当本地存储中无数据或解析失败时，加载预置种子活动数据
- 每次新增、编辑、上下架、删除后均立即回写本地存储

## 9. 规则与边界条件

- 权限规则：页面文案明确"统一由平台运营负责人创建"，当前实现未区分更多角色权限，也未提供只读/只编辑差异控制。
- 状态流转规则：
  - 新建和保存编辑后统一进入"已上架"状态
  - 手动下架后状态变为"已下架"
  - 已下架活动可在列表页重新上架
  - 未手动下架时，状态会依据当前时间自动在"已上架 / 进行中 / 已下架"间归一化
- 数据限制：
  - 活动仅可选择单一渠道
  - 一个活动可绑定该渠道下多个机构
  - 每个机构维护独立项目清单和活动价
  - 活动项目来自预置标准项目库
- 异常场景：
  - 本地存储解析失败时回退为默认数据
  - 详情页活动不存在时展示空态提示
  - 未选择机构时不能添加检查项目
  - 未选项目时点击确认添加会提示先选择项目

## 10. 数据与指标

如何判断需求是否成功？

- 核心指标：
  - 平台运营负责人可成功创建活动并返回列表
  - 活动可按机构维度维护项目活动价
  - 同渠道同机构同项目在重叠时间内无法重复配置
- 观察指标：
  - 活动上下架成功率
  - 活动删除成功率
  - 详情页价格核查可用性
- 埋点 / 数据需求：当前代码未实现埋点需求；如后续接入埋点，建议记录新建、编辑、上下架、删除、项目添加、项目移除和冲突命中行为。

## 11. 风险与依赖

- 技术依赖：依赖 React、Ant Design、React Router、dayjs 和浏览器本地存储能力。
- 产品依赖：依赖渠道、机构、标准项目库及默认活动价的基础数据定义。
- 运营依赖：依赖平台运营负责人对活动名称、时间、机构范围和项目价格进行维护。
- 风险点：
  - 当前仅使用本地存储，刷新浏览器或更换环境后的数据一致性依赖当前浏览器上下文
  - 未接入真实权限系统，默认所有访问者均可执行编辑类操作
  - 删除后不可恢复，若误删需重新创建活动

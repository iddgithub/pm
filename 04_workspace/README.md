# 04_workspace

`04_workspace/` 是 `pm_agent` 当前最活跃的工作层，用来承接正在推进的需求、原型、PRD、demo 和讨论。

如果说 `03_context/` 解决“稳定知识放哪里”，那么 `04_workspace/` 解决“正在做的事情放哪里”。

## 目录关系

- `prd/`：按专题目录维护需求分析、原型和 PRD
- `demos/`：H5 / PC 演示工程、运行脚本和说明
- `bugs/`：缺陷记录、现象整理、排查线索
- `discussions/`：较大的需求讨论或方案讨论
- `公众号/`：公众号选题和内容产出
- `关键会议纪要/`：重要会议的结构化记录

## 推荐用法

1. 新需求先进入 `prd/某个专题/`
2. 演示页面和可运行工程进入 `demos/`
3. 问题记录先进入 `bugs/` 或专题 `analysis/`
4. 较大的讨论过程先放 `discussions/`
5. 稳定规则再从这里提炼到 `03_context/`

## 和其他层的边界

- 与 `05_drafts/` 的区别：
  `05_drafts/` 放未成型想法，`04_workspace/` 放已经进入推进状态的工作

- 与 `03_context/` 的区别：
  `04_workspace/` 放过程和阶段性产出，`03_context/` 放稳定可复用结论

## 维护原则

- 一项需求尽量在一个专题目录内持续推进
- 过程文档允许迭代，但要保持结构清楚
- 已完成且可复用的内容，及时上收进 `03_context/`

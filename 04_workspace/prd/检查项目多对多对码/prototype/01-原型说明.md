# 检查项目多对多对码原型说明

本目录用于承接“检查项目多对多对码 1.0”专题的后台页面原型。

## 当前文件

- `02-检查项目多对多对码后台原型.html`：后台四页面静态原型
- `project-mapping-prototype.css`：原型样式文件
- `03-cms院内检查项目对码高保真原型.html`：基于线上 CMS `#/checkHospitalItem` 还原的高保真交互原型
- `cms-hospital-item-replica.css`：高保真原型样式文件
- `cms-hospital-item-replica.js`：高保真原型交互脚本
- `04-URL还原基线.md`：本次 URL 还原的来源、样式 token 和交互边界说明
- `05-cms平台项目列表高保真原型.html`：基于线上 CMS `#/itemManage` 还原的平台项目列表高保真交互原型
- `cms-item-manage-replica.css`：平台项目列表专属补充样式
- `cms-item-manage-replica.js`：平台项目列表交互脚本
- `06-cms平台项目列表URL基线.md`：平台项目列表的 URL 基线与详情态边界说明
- `07-cms组合对码高保真原型.html`：从院内检查项目对码页复制出的独立组合对码页，单独承接组合规则方案输出

## 原型范围

1. `中心标准项目库`
   - 展示标准项目列表、筛选区、状态管理和批量导入入口
   - 展示标准项目字段结构与编辑侧栏

2. `上游项目对码管理`
   - 展示上游项目列表
   - 支持把一个上游项目映射到多个中心标准项目
   - 展示解析结果和保存规则

3. `交付中心项目对码管理`
   - 展示交付中心项目列表
   - 支持单项目、组合套餐、加收项配置
   - 支持优先级设置和覆盖项目查看

4. `订单匹配日志 / 异常处理`
   - 展示订单匹配结果
   - 展示异常订单、失败原因和重新匹配入口

5. `CMS 院内检查项目对码高保真还原`
   - 还原登录壳、左侧导航、顶部医院切换条和目标页内容结构
   - 支持单条新增 / 编辑、AI 对码、批量对码、项目导出、模版导出
   - 用静态演示数据模拟价格拆分、设备绑定和平台项目回填

6. `CMS 平台项目列表高保真还原`
   - 还原左侧导航、顶部医院切换条、平台项目列表页和分页区
   - 支持检查类型筛选、编码/名称关键字搜索和详情阅读态
   - 用静态演示数据模拟平台项目标准词条和详情说明

7. `CMS 组合对码高保真方案页`
   - 复制院内检查项目对码页作为独立入口，避免污染原页面
   - 保留同一套后台壳、筛选区和列表信息密度
   - 用示例规则演示“上游组合医嘱 -> 平台标准项目 -> 交付中心执行项目”的配置方案

## 使用方式

直接打开 `02-检查项目多对多对码后台原型.html` 可查看专题四页面静态原型。

直接打开 `03-cms院内检查项目对码高保真原型.html` 可查看基于线上 CMS 页面的高保真交互还原原型。

直接打开 `05-cms平台项目列表高保真原型.html` 可查看基于线上 CMS `#/itemManage` 页面的高保真交互还原原型。

直接打开 `07-cms组合对码高保真原型.html` 可查看从检查项目对码页拆出的独立组合对码方案页。

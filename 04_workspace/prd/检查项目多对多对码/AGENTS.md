# 检查项目多对多对码

本文件是 Codex 在“检查项目多对多对码”专题目录下的工作索引。

## 用途

本目录用于承接检查项目标准化、多对多对码、订单匹配下发和异常处理的全过程文档，是该专题的统一入口。

## 当前文件

- `README.md` — 专题说明、目录结构和推进建议
- `analysis/` — 需求分析、规则拆解、数据实体建议、待确认问题
- `prototype/` — 后台页面原型、交互方案、页面说明
- `prd/` — 正式 PRD、版本功能清单和验收范围

## 维护规则

- 项目主数据、对码规则、匹配逻辑、异常闭环优先进入 `analysis/`
- 页面结构、信息架构、操作流程和静态原型优先进入 `prototype/`
- 版本范围、功能清单、验收标准统一进入 `prd/`
- 本专题聚焦“检查项目标准化与映射体系”，不要混入医生合规开单、医生角色分工等无直接关系的专题内容

# 检查项目多对多对码

本专题用于集中沉淀“检查项目多对多对码 1.0”相关的需求分析、后台原型和正式 PRD，避免继续分散在其他业务专题中。

## 目录结构

```text
检查项目多对多对码/
├── README.md
├── AGENTS.md
├── analysis/
├── prototype/
└── prd/
```

## 建议放置内容

- `analysis/`：业务背景、问题定义、规则拆解、数据实体、待确认问题
- `prototype/`：后台页面结构、交互草图、静态演示页
- `prd/`：版本目标、正式需求说明、功能清单、验收标准

## 当前建议

1. 先围绕“中心标准项目库 + 上游对码 + 下游对码 + 订单匹配异常闭环”完成 1.0 收敛。
2. 计费规则、省份加收、智能推荐等能力暂时不要并入本期范围。
3. 页面评审、字段评审和匹配规则评审，应统一以本专题目录下文档为准。

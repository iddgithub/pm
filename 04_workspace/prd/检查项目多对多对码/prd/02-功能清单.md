# 检查项目多对多对码 1.0 功能清单

## 说明

- 本清单用于产品、研发、测试对齐 1.0 交付范围。
- 优先级说明：
  - `P0`：1.0 必须交付
  - `P1`：建议交付，但不阻塞主闭环

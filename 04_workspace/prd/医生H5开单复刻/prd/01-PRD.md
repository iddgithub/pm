# 医生H5开单复刻 PRD（首版）

## 一、需求背景

当前需要把已上线的医生 H5 自助检查开单产品复刻到本地 demo 工程中，作为后续连续迭代的基础版本。后续改动不再基于口头描述从零生成，而是直接在这套复刻产物上持续修改。

## 二、需求目标

1. 在现有 H5 demo 工程中新增独立产品路由。
2. 页面与流程尽量贴近线上产品和操作手册截图。
3. 首版先覆盖关键流程与状态，不做真实后端接入。
4. 支持后续通过对话继续修改页面、文案、规则和结构。

## 三、交付范围

### 页面范围

- 医生开单首页
- 添加项目页面
- 机构列表页面
- 锁单分享页面
- 订单状态页面
- 患者支付页面

### 文档范围

- 需求分析
- 原型说明
- 首版 PRD

## 四、验收标准

- 可通过本地 H5 地址直接访问独立路由。
- 页面视觉能对应手册中的关键截图风格。
- 页面之间能够演示完整主流程。
- 订单状态可切换查看不同状态表现。
- 患者支付页可展示就诊人信息锁定弹窗。

## 五、后续版本建议

1. 接入更接近线上字段的 mock 数据。
2. 拆分医生端与患者端的更细状态。
3. 如有需要，再补分享后二维码页、支付完成页、报告完成页等单独页面。

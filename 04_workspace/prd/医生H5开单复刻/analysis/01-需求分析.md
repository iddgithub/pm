# 医生H5开单复刻需求分析

## 目标

在 `04_workspace/demos/h5/` 中复刻一个独立的“医生 H5 自助检查开单”产品原型，方便后续通过对话持续修改页面、字段、流程和状态规则。

## 信息来源

1. 线上链接：`https://m.imavine.com/share/pages/coverPage/index`
2. 操作手册：`一脉青藤H5自助检查开单产品操作手册 (2).docx`

## 交叉验证结论

- 操作手册明确了主链路：首次进入授权登录、项目选择、机构选择、订单锁定分享、订单状态追踪。
- 手册中的高保真截图补足了关键视觉细节：
  - 医生开单首页
  - 添加项目弹层
  - 机构列表页
  - 订单状态页
  - 患者支付页与“就诊人信息锁定”弹窗
- 线上入口返回的是 `/share/` 下的独立 H5 单页应用，页面标题为“一脉青藤”。

## 首版复刻范围

### 医生端

- 开单首页：
  - 主诉描述
  - 预约时间快捷选择
  - 添加项目 / AI项目推荐入口
  - 已选项目列表
  - 查询机构按钮
- 添加项目：
  - CT / DR / MR 模态切换
  - 部位分组
  - 项目列表勾选
  - 智能排序入口
  - 已选数量与确认操作
- 机构列表：
  - 日期卡片
  - 距离最近 / 只看三甲 / 只看公立筛选
  - 机构卡片、标签、距离与确认机构
- 锁单分享：
  - 机构信息
  - 检查项目与金额
  - 添加就诊人
  - 扫码开单 / 分享订单给患者

### 状态页

- 已开单分享，待24小时内支付
- 已超时，自动取消
- 已支付
- 已完成
- 已退费

### 患者端

- 就诊人信息填写
- 预约时间展示
- 协议勾选
- 提交支付按钮
- 就诊人信息已绑定后的禁止修改提示弹窗

## 首版不做

- 真实登录
- 真实接口联调
- 微信分享能力
- 实际支付
- 真实地图与导航

## 后续迭代重点

1. 补足首页更多字段，例如症状描述、推荐理由、AI推荐反馈状态。
2. 细化机构筛选规则，例如支持模态、时间段库存、距离排序与城市范围。
3. 细化订单锁定与修改边界，例如分享前后可编辑字段差异。
4. 如需接近线上，可再补真实接口字段映射与状态流转逻辑。

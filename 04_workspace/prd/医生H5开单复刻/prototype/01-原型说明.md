# 医生H5开单复刻原型说明

## 原型定位

本原型不是把旧的医生激励 H5 混入现有页面，而是在现有 H5 demo 工程内新增一个独立路由，专门承接“医生给患者开单”的产品复刻与后续迭代。

路由建议：

- `http://127.0.0.1:3001/doctor-ordering`

## 页面映射

### 1. 开单首页

- 对应手册中的医生端首页截图
- 重点复刻：
  - 主诉描述输入框
  - 预约时间快捷入口
  - 添加项目卡片
  - AI项目推荐卡片
  - 已选项目列表
  - 查询机构主按钮

### 2. 添加项目

- 对应手册中的“点击添加项目”弹层
- 重点复刻：
  - 顶部搜索框
  - CT / DR / MR 模态切换
  - 左侧部位分组
  - 右侧项目勾选卡片
  - 底部已选数量与确认按钮

### 3. 机构列表

- 对应手册中的机构筛选页面
- 重点复刻：
  - 顶部预约日期卡片
  - 快速筛选项
  - 机构卡片
  - 距离信息
  - 标签体系

### 4. 锁单分享

- 结合手册步骤4与订单详情截图复刻
- 重点复刻：
  - 机构信息卡
  - 项目费用明细
  - 总金额
  - 扫码开单 / 分享订单按钮
  - 分享后锁定提示

### 5. 订单状态

- 对应手册中的五种订单状态截图
- 重点复刻：
  - 已开单分享
  - 已超时
  - 已支付
  - 已完成
  - 已退费

### 6. 患者支付页

- 对应患者端信息填写与锁定弹窗
- 重点复刻：
  - 就诊人信息
  - 预约时间
  - 协议勾选
  - 提交支付按钮
  - 禁止修改弹窗

## 交互约定

- 页面之间允许通过内部导航按钮切换，便于演示与后续修改。
- 首版不依赖真实接口，先用前端 mock 数据维持完整故事线。
- 所有视觉与状态组件保留清晰的类名和数据结构，方便后续细化。

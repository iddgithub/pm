# 互联网医生端

本专题用于集中调整互联网医生侧“承接上下文 -> 在线问诊确认 -> 生成支付订单”的页面方案，并纳入互联网医生执行视角的前置入驻约束。

## 目录结构

```text
互联网医生端/
├── README.md
├── analysis/
├── prototype/
└── prd/
```

- `analysis/01-需求分析.md`：互联网医生端角色边界、页面范围和关键规则分析
- `analysis/02-待确认问题.md`：互联网医生端待确认问题

- `prototype/02-互联网医生端诊前问诊原型.html`：互联网医生端聚合原型

- `prd/01-PRD.md`：互联网医生端 PRD 第一稿

# 价格管理专题

本目录承接“价格管理 / 活动分层管理”相关需求。

## 专题边界

- 解决互联网医院不同价、交付中心价格活动、平台通用优惠券三类价格配置的产品方案。
- 明确主套优惠不在价格管理中临时拼套餐，而应先通过“组合项目 / 对码多对多”形成可售卖项目。
- 沉淀用于领导汇报、评审和 PC 后台 demo 改造的需求文档。

## 目录约定

- `analysis/`：会议纪要拆解、业务闭环和待确认事项。
- `prototype/`：页面结构、交互说明和演示稿。
- `prd/`：正式 PRD 或评审稿。

## 工作要求

1. 默认使用简体中文。
2. 未确认的结算、报告机构收费等问题先记录为待确认，不写成已定规则。
3. 页面 demo 仅表达产品方案，不默认代表真实后端已实现。
4. 稳定规则后续再提炼到 `03_context/`。

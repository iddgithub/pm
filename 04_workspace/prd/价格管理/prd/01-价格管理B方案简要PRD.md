# 价格管理 B 方案简要 PRD

**文档状态**：Draft  
**负责人**：胡高鹏  
**创建日期**：2026-07-01  
**适用页面**：PC 后台 / 产品功能 / 价格管理

## 1. 背景

原“活动管理”方案把多类价格问题放在同一个活动规则里，包括互联网医院不同价、交付中心活动价、用户优惠券和主套优惠。会议讨论后确认，这种建模不利于解释业务主体，也容易造成价格冲突。

本次调整目标是把活动管理中承载的价格能力拆成“价格管理”，用更清晰的业务闭环表达：谁在定价、谁在优惠、谁负责履约、订单如何结算。

## 2. 核心方案

价格管理采用三类配置：

| 类型 | 解决问题 | 定价依据 | 示例 |
|---|---|---|---|
| 互联网医院价格活动 | 不同互联网医院 / 来源平台对同一项目展示不同价格 | 互联网医院项目价格 | 平安好医生下肺结节 AI 展示 129 元 |
| 交付中心价格活动 | 某交付中心自身项目做阶段性活动价 | 交付中心项目价格 | 成都高新影像中心 CT 骨密度活动价 138 元 |
| 平台通用优惠 | 用户侧优惠券 / 折扣券 | 用户、券、订单条件 | 新客券满 200 减 30 |

一句话逻辑：

> 价格活动决定“项目本身卖多少钱”；平台通用优惠决定“这个用户还能减多少钱”。

## 3. 业务闭环

```text
项目主数据准备
  -> 活动 / 优惠配置
  -> 用户进入下单
  -> 系统识别来源、项目、履约中心和用户权益
  -> 计算展示价、优惠金额、支付价
  -> 支付后派单履约
  -> 订单记录价格来源并进入结算复盘
```

### 3.1 项目先行

价格管理不负责创建项目。

- 单项目：由项目库维护。
- 组合项目 / 主套项目：由互联网医院项目或“对码多对多”形成可售卖项目。
- 价格管理只对已经存在的可售卖项目配置价格活动或优惠适用条件。

### 3.2 下单计算顺序

1. 识别售卖主体：互联网医院 / 来源平台 / 交付中心。
2. 识别可售卖项目：单项目或组合项目。
3. 识别履约交付中心。
4. 命中对应价格活动。
5. 判断用户是否有可用平台优惠。
6. 输出展示价、优惠金额、支付价和结算记录。

## 4. 主套优惠处理原则

主套优惠不作为价格管理中的一级活动类型。

原因：

- 主套本质是“组合项目”，不是简单满减。
- 组合项目需要先解决互联网医院项目、平台标准项目、交付中心院内项目之间的映射。
- 价格管理如果临时拼套餐，会绕开对码和履约，后续结算会失真。

处理方式：

- “胸腹联扫”等主套先在组合项目 / 对码多对多体系中形成可售卖项目。
- 形成可售卖项目后，价格管理可对该组合项目设置互联网医院价格活动、交付中心价格活动或平台通用优惠。

## 5. 页面需求

### 5.1 菜单

在 PC 后台“产品功能 > 活动管理”下方新增：

- 价格管理

### 5.2 页面结构

价格管理页面包含：

1. 方案说明区：说明三类配置和主套优惠处理原则。
2. 业务闭环区：展示从项目准备到结算复盘的链路。
3. 三类配置切换：
   - 互联网医院价格活动。
   - 交付中心价格活动。
   - 平台通用优惠。
4. 配置列表：展示名称、类型、定价主体、项目 / 条件、价格或优惠、适用范围、状态、冲突口径。
5. 详情弹窗：解释该配置在下单闭环中如何被命中、如何影响价格和结算。

## 6. 冲突规则

### 6.1 同层冲突禁止

同一层级内，同一时间段、同一主体、同一项目不允许存在两条有效价格配置。

示例：

- 同一互联网医院 + 同一来源平台 + 同一项目 + 同一履约中心 + 时间重叠，只允许一条互联网医院价格活动。
- 同一交付中心 + 同一中心项目 + 时间重叠，只允许一条交付中心价格活动。
- 同一用户范围 + 同一券条件 + 同一使用场景，需限制重复发放和重复使用。

### 6.2 跨层按计算顺序处理

不同层级可以同时存在，但必须在订单价格计算时按顺序处理：

```text
基础价 / 项目价
  -> 互联网医院价格活动或交付中心价格活动
  -> 平台通用优惠
  -> 用户支付价
```

## 7. 本期不做

- 不在价格管理中创建主套 / 组合项目。
- 不实现真实价格引擎。
- 不处理报告机构收费归属。
- 不处理复杂审核流。
- 不接入真实券发放系统。

## 8. 验收标准

- 后台菜单在活动管理下方展示“价格管理”。
- 价格管理页面能清楚表达三类配置模型。
- 页面能说明主套优惠为何移出一级活动类型。
- 页面能展示下单、价格计算、履约、结算的完整闭环。
- 页面 demo 能区分互联网医院价格活动、交付中心价格活动和平台通用优惠。

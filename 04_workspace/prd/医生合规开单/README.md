# 医生合规开单

本专题用于集中沉淀“医生合规开单”相关的需求分析、原型方案和正式 PRD，并作为原 `诊所医生端/` 相关内容的唯一继续维护入口。

## 目录结构

```text
医生合规开单/
├── README.md
├── AGENTS.md
├── analysis/
├── prototype/
└── prd/
```

## 建议放置内容

- `analysis/`：合规边界、角色流程、规则拆解、待确认问题
- `prototype/`：原型说明、页面结构、交互稿、静态页面稿
- `prd/`：正式 PRD、评审稿、版本方案

## 当前建议

1. 后续所有与医生开单相关的线下录入、机构选择、开单确认、问诊入口、报告解读与提现链路，都统一在本专题内继续维护。
2. 合规规则、状态流转和待确认问题优先收敛进 `analysis/`。
3. 页面方案和角色链路统一收敛进 `prototype/`，避免再拆回独立“诊所医生端”目录。
4. 页面与规则稳定后，再继续沉淀到 `prd/`。

# 医生合规开单

本文件是 Codex 在“医生合规开单”专题目录下的工作索引。

## 用途

本目录用于承接医生合规开单专题的全过程文档，是该专题的统一入口。
原 `04_workspace/prd/诊所医生端/` 已并入本目录，后续不再单独维护。

## 当前文件

- `README.md` — 专题说明、目录结构和推进建议
- `analysis/` — 合规规则、诊所医生端链路分析、待确认问题
- `prototype/` — 高保真原型、诊所医生端页面稿、交互方案
- `prd/` — 正式 PRD、评审稿、补充版本说明

## 当前原型

- `prototype/01-原型说明.md` — 当前高保真原型说明
- `prototype/02-医生合规开单高保真原型.html` — 高保真页面原型
- `prototype/03-一脉青藤页面总览.html` — 单页总览，集中展示“我的任务 / 患者管理 / 患者详情 / 检查检验”
- `prototype/04-诊所医生端原型说明.md` — 原诊所医生端原型说明
- `prototype/05-诊所医生端报告解读业务原型.html` — 原诊所医生端聚合原型
- `prototype/06-线下采集患者信息页.html` 至 `prototype/10-预约确认与扫码开单页.html` — 线下录入、机构选择、开单确认与扫码链路页面
- `prototype/appointment-pages.css` — 原诊所医生端页面样式
- `prototype/compliance-ordering-prototype.css` — 原型样式文件

## 维护规则

- 合规规则、角色边界、流程约束优先进入 `analysis/`
- 页面方案、信息架构、原型稿优先进入 `prototype/`
- 版本目标、范围定义、验收口径统一进入 `prd/`
- 不再新增或恢复独立的 `诊所医生端/` 主题目录

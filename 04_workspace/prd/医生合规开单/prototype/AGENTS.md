# 医生合规开单 / prototype

本目录用于沉淀“医生合规开单”专题下的页面原型和交互稿。

## 当前文件

- `01-原型说明.md` — 原型范围与文件说明
- `02-医生合规开单高保真原型.html` — 高保真页面原型，包含“检查检验 / 我的任务 / 患者管理 / 患者详情”
- `03-一脉青藤页面总览.html` — 将当前识别出的 4 个核心页面集中展示在一个浏览器页面内
- `04-诊所医生端原型说明.md` — 原诊所医生端原型说明
- `05-诊所医生端报告解读业务原型.html` — 原诊所医生端聚合原型
- `06-线下采集患者信息页.html` — 线下采集患者信息页
- `07-诊前问诊二维码页.html` — 问诊入口二维码页
- `08-医生检查开单页.html` — 检查开单页
- `09-检查机构选择页.html` — 机构选择页
- `10-预约确认与扫码开单页.html` — 预约确认与扫码开单页
- `appointment-pages.css` — 诊所医生端页面样式文件
- `compliance-ordering-prototype.css` — 原型样式文件

## 维护规则

- 页面结构、布局、交互流优先放在本目录
- 新增原型页时，优先继续沿用现有编号顺序
- 若新增二级页面或详情页，优先继续并入当前原型文件或在说明文档补充页面关系
- 原 `诊所医生端/` 相关页面统一在本目录续写，不再拆回独立专题

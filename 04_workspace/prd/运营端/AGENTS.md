# 运营端

本文件是 Codex 使用的目录索引。

## 用途

本目录用于沉淀运营端专题的全过程文档，是该专题的目录级导航入口。

## 当前文件

- `README.md` — 专题说明、当前内容和后续推进建议
- `analysis/01-需求分析.md` — 运营端需求分析主文档
- `analysis/02-待确认问题.md` — 运营端待确认问题
- `analysis/03-合规化流程会议结论与产品解决方案.md` — 合规流程会议结论全文
- `analysis/04-运营绑定与互联网医生入驻补充.md` — 运营绑定与入驻补充分析
- `prototype/01-原型说明.md` — 运营端原型说明
- `prototype/02-运营端医生绑定与入驻原型/` — 运营端原型目录
- `prototype/03-运营绑定与互联网医生入驻原型说明.md` — 运营端三页原型说明
- `prd/01-PRD.md` — 运营端 PRD 第一稿
- `prd/02-运营绑定与入驻补充PRD.md` — 运营端补充 PRD

## 维护规则

- 页面结构、运营操作路径和信息展示优先进入 `prototype/`
- 业务规则、角色边界和待确认项优先进入 `analysis/`
- 正式需求范围、版本目标和验收标准统一进入 `prd/`

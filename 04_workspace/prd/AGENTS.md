# PRD Workspace

本文件是 Codex 在 `04_workspace/prd/` 目录中的工作索引。

## 用途

这里存放 pm_agent 当前正在推进的需求专题，采用“一个需求一个目录”的方式维护全过程文档，而不是把所有 PRD 平铺在根目录。

## 目录规则

每个专题目录默认采用以下结构：

```text
某个需求专题/
├── README.md
├── analysis/
├── prototype/
└── prd/
```

## 当前专题

- `患者端/`：患者查看报告、查看解读内容与提交评价专题，作为患者侧原型独立维护入口
- `诊所医生端/`：诊所医生接单、解读、收益汇总与打款记录专题，作为医生侧原型独立维护入口
- `互联网医生端/`：互联网医生扫码接诊、问诊确认与支付订单生成专题，作为互联网医生侧原型独立维护入口
- `运营端/`：运营绑定医生、查看订单与医生入驻审核专题，作为运营侧原型独立维护入口
- `订单数据导出需求/`：销售数据导出问题的需求沟通与后续方案沉淀入口
- `医生H5开单复刻/`：独立医生开单 H5 产品的复刻专题，包含分析、原型说明与首版 PRD

## 当前公共文件

- `PRD模板.md`：通用 PRD 模板，适用于新专题起草
- `README.md`：本目录的专题式维护说明
- `2026-05-13-四角色重组迁移说明.md`：四角色重组后的迁移说明与旧目录停用说明

## 维护规则

1. 新需求统一在本目录下新建专题目录。
2. `analysis/` 先承接需求分析、规则澄清和待确认事项。
3. `prototype/` 放原型说明、交互方案和页面结构。
4. `prd/` 放正式 PRD、评审稿和定稿。
5. 已稳定为通用规则的内容，应提炼后迁移到 `03_context/`。

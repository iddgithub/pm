# PM能力层赋能建设

本专题用你的这次真实需求做一次完整演示：如何把 `01_agents/`、`02_tools/` 和 `04_workspace/prd/` 串起来，跑出一条标准的产品工作流。

## 目录结构

```text
PM能力层赋能建设/
├── README.md
├── analysis/
├── prototype/
└── prd/
```

## 这次演示怎么跑

1. 先用 `01_agents/角色定义/产品策略顾问.md`
2. 再套 `02_tools/模板/需求分析输入卡.md`
3. 然后由 `01_agents/角色定义/需求分析师.md` 输出分析
4. 再整理目录原型到 `prototype/`
5. 最后由 `01_agents/角色定义/PRD写作助手.md` 输出正式 PRD

## 当前内容

- `analysis/00-需求分析输入卡.md` — 按 `02_tools/模板/需求分析输入卡.md` 填写的真实输入
- `analysis/01-需求分析.md` — 按 `需求分析师` 角色输出的结构化分析
- `prototype/01-原型说明.md` — 本次能力层的目录原型说明
- `prd/01-PRD.md` — 正式 PRD 第一稿

## 你应该怎么看

- 如果你想学“先怎么想”，先看 `analysis/00-需求分析输入卡.md`
- 如果你想学“怎么拆需求”，看 `analysis/01-需求分析.md`
- 如果你想学“怎么落成正式文档”，看 `prd/01-PRD.md`

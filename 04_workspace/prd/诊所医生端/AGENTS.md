# 诊所医生端

本文件是 Codex 使用的目录索引。

## 用途

本目录用于沉淀诊所医生端专题的全过程文档，是该专题的目录级导航入口。

## 当前文件

- `README.md` — 专题说明、当前内容和后续推进建议
- `analysis/01-需求分析.md` — 诊所医生端需求分析主文档
- `analysis/02-待确认问题.md` — 诊所医生端待确认问题
- `analysis/03-线下诊所问诊入口二维码归档说明.md` — 二维码入口补充归档说明
- `prototype/01-原型说明.md` — 诊所医生端原型说明
- `prototype/02-诊所医生端报告解读业务原型.html` — 诊所医生端聚合原型，保留原报告解读链路并新增一行展示 3 个开单页面
- `prototype/03-线下采集患者信息页.html` — 线下采集单页
- `prototype/04-诊前问诊二维码页.html` — 问诊入口二维码单页
- `prototype/05-医生检查开单页.html` — 诊所医生检查开单新增页面
- `prototype/06-检查机构选择页.html` — 机构筛选与列表新增页面
- `prototype/07-预约确认与扫码开单页.html` — 开单确认与扫码新增页面
- `prd/01-PRD.md` — 诊所医生端 PRD 第一稿
- `prd/02-线下诊所问诊入口二维码补充PRD.md` — 问诊入口二维码补充 PRD

## 维护规则

- 页面结构、医生操作路径和信息展示优先进入 `prototype/`
- 业务规则、角色边界和待确认项优先进入 `analysis/`
- 正式需求范围、版本目标和验收标准统一进入 `prd/`

# 诊所医生端 PRD

## 一、需求背景

诊所医生在当前业务中既承担检查前的线下接诊与患者上下文录入，也承担检查后的报告解读服务承接、收益查看和提现动作。原有内容分散在不同专题中，现统一收口到诊所医生端目录。

## 二、需求目标

### 2.1 业务目标

- 让诊所医生可以标准化提交患者上下文并引导患者进入线上问诊。
- 让诊所医生在后链路中可以清晰承接解读任务并查看收益。

### 2.2 用户目标

- 能快速完成接诊信息录入。
- 能方便展示线上问诊入口给患者。
- 能查看待处理任务、已解读记录和提现数据。

## 三、页面范围

1. 线下采集患者信息页
2. 诊前问诊二维码页
3. 报告解读任务列表
4. 报告详情与模版确认
5. 已解读与服务费汇总
6. 打款记录

## 四、关键规则

1. 诊所医生录入的信息应减少患者线上重复确认成本。
2. 入口码服务于本次业务，而不是长期个人入口。
3. 解读任务派发遵循平台规则，不再简单按来源医生回派。
4. 收益、提现与服务完成记录保持一致。

# 04_workspace/prd 维护说明

本目录从“平铺文件”调整为“专题目录制”，用于记录每个需求从分析、原型到 PRD 的完整过程。

## 标准结构

```text
04_workspace/prd/
├── README.md
├── PRD模板.md
├── 需求专题A/
│   ├── README.md
│   ├── analysis/
│   ├── prototype/
│   └── prd/
└── 需求专题B/
    ├── README.md
    ├── analysis/
    ├── prototype/
    └── prd/
```

## 命名约定

- 专题目录：直接使用需求主题命名
- 分析文档：`01-需求分析.md`
- 原型文档：`01-原型说明.md`
- PRD 文档：`01-PRD.md`
- 沟通记录：`YYYY-MM-DD-沟通记录.md`

## 使用顺序

1. 先在 `analysis/` 做需求分析和规则澄清。
2. 再在 `prototype/` 整理页面结构和交互方案。
3. 最后在 `prd/` 输出正式 PRD。

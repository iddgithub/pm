# 患者端

本专题用于集中调整患者查看报告、查看医生解读内容、完成支付承接与提交评价的页面方案，作为患者侧独立维护入口。

## 目录结构

```text
患者端/
├── README.md
├── analysis/
├── prototype/
└── prd/
```

## 当前内容

- `analysis/01-需求分析.md`：患者端角色边界、页面范围和关键规则分析
- `analysis/02-待确认问题.md`：患者入口、支付、报告查看与评价相关待确认问题
- `prototype/01-原型说明.md`：患者端原型说明
- `prototype/02-患者端报告查看与评价原型.html`：患者端查看报告与评价聚合原型
- `prototype/03-患者已出报告详情页.html`：患者查看报告与解读入口单页
- `prototype/04-患者报告解读与评价页.html`：患者查看解读与评价单页
- `prd/01-PRD.md`：患者端 PRD 第一稿

## 后续建议

1. 先继续补齐“支付前确认 -> 查看报告 -> 查看解读 -> 服务评价”的完整患者链路。
2. 需要明确字段、状态和评价规则时，优先补到 `analysis/`。
3. 页面方案稳定后，再继续细化 `prd/01-PRD.md`。

# 患者端

本文件是 Codex 使用的目录索引。

## 用途

本目录用于沉淀患者侧查看报告与评价专题的全过程文档，是该专题的目录级导航入口。

## 当前文件

- `README.md` — 专题说明、当前内容和后续推进建议
- `analysis/01-需求分析.md` — 患者端需求分析主文档
- `analysis/02-待确认问题.md` — 患者端待确认问题
- `prototype/01-原型说明.md` — 患者端原型说明
- `prototype/02-患者端报告查看与评价原型.html` — 患者端聚合原型
- `prototype/03-患者已出报告详情页.html` — 患者查看报告单页
- `prototype/04-患者报告解读与评价页.html` — 患者解读评价单页
- `prd/01-PRD.md` — 患者端 PRD 第一稿

## 维护规则

- 页面结构、患者操作路径和信息展示优先进入 `prototype/`
- 规则澄清、状态说明和待确认项优先进入 `analysis/`
- 正式需求范围、版本目标和验收标准统一进入 `prd/`
